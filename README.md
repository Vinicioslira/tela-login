# 🔐 Tela de Login

Projeto de uma tela de login desenvolvido para praticar conceitos de desenvolvimento web e estilização com CSS.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3

## 📚 Objetivo

Projeto desenvolvido como parte dos meus estudos e práticas em desenvolvimento web, trabalhando principalmente com estrutura HTML, estilização CSS, formulários e organização de layout.

## ✨ Funcionalidades

* Campo de usuário/e-mail
* Campo de senha
* Botão de login
* Interface responsiva
* Fundo com imagem
* Efeito de transparência e desfoque
